# Changelog

## v0.1.0

- Public monorepo baseline published under `minislively/wasm-first-workflow-editor`
- Runnable `Web Component` demo and React host demo
- Worker-aware engine controller with `WebGL` primary renderer seam and Canvas fallback
- Rust/WASM kernel crate plus `wasm-pack` bridge and safe TypeScript fallback
- Benchmark fixtures for `100`, `500`, and `1000` nodes
- CI verification for pnpm, Rust, wasm-pack, builds, and smoke checks
- Adoption docs for `Web Component`, React host guidance, and non-React host embedding
